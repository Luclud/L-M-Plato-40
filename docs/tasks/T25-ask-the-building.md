# T25 — "Ask the building" copilot page (optional, explain-only)

**Lane:** C · **Priority:** P2 · **Depends on:** T18 · **Score impact:** demo (8), decision & action trail (7)

## Goal
A chat page where the jury can ask about the loaded run ("What happened in Room 104?", "Which incidents still need
approval?", "Why was the on-call housekeeper called on 24 Jan?") and get answers grounded in the decision log, with
citations (`docs/FRONTEND_PLAN.md` §7a). The copilot reads; it never decides, approves or changes anything.

## Do
- `viewer/copilot.py`: Claude tool use (model from `.env`, default e.g. `claude-sonnet-5-5`; `anthropic` SDK in
  `viewer/requirements.txt` only, MIT licence — or HTTP like `plato40/llm.py`). Read-only tools over the loaded run:
  `list_incidents(type?, asset?, date_from?, date_to?, needs_approval?)`, `get_incident(episode_id)`,
  `get_decision(event_id)`, `get_evidence(episode_id)`, `count_by_type()`, `pending_approvals()`. Results are trimmed JSON.
- System prompt: answer only from tool results; cite decision ids `[D000123]`; say "not in the decision log" otherwise;
  simulated effects are simulated, messages are proposed, approvals are mock; use friendly names from `viewer/labels.py`.
- `viewer/views/ask.py`: `st.chat_input` + history; citations rendered as links to the story page (`?episode=`); 4 suggested
  questions as buttons; label "AI answer from the decision log — check the cited decisions".
- Offline/demo safety: `viewer/copilot_cache.json` with answers to the suggested questions for quickstart (generated by a
  `--build-cache` flag); used when no key or no network. No key → page explains how to enable it and shows cached examples.
- Limits: max 6 tool calls per question, 30 s timeout, friendly error.

## Acceptance criteria
- Tests with a mock client: tool calls dispatched correctly, citations rendered as links, unknown questions → "not in the
  decision log", no tool can write anything.
- Works without a key (cached examples) and with a key (manual check, note 3 example Q&As in the PR). Key never committed.
